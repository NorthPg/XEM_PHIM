# The Little Garden — A Little Surprise for You 🌸

Website quà tặng tương tác nhân ngày Phụ nữ Việt Nam 20/10 với phong cách thơ mộng, dịu dàng và tinh tế.

## 🌷 Tính Năng Nổi Bật

1. **Hành trình 7 màn hình:**
   - **Màn 1:** Cánh Cổng Bí Mật với ổ khóa hoa vàng phát sáng.
   - **Màn 2 (Game 1):** Đánh thức 3 nụ hoa ngái ngủ để hoa nở rộ.
   - **Màn 3:** Hé lộ bức ảnh Polaroid đầu tiên (hỗ trợ lật 3D xem mặt sau ảnh).
   - **Màn 4 (Game 2):** Thu thập 5 chú đom đóm vào bình thủy tinh, mở khóa cùng lúc Ảnh 2 & Ảnh 3.
   - **Màn 5 (Game 3):** Ghép 4 mảnh hoa hoàn mỹ 2x2, mở khóa Ảnh 4.
   - **Màn 6:** Lựa chọn 1 trong 3 chiếc hộp may mắn với lời chúc ngọt ngào, mở khóa Ảnh 5.
   - **Màn 7:** Bức thư tay chúc mừng 20/10, Hero Ảnh 5, Album tổng hợp 5 ảnh có thể bấm xem to toàn màn hình (Lightbox).
2. **Trang Bí Mật (Easter Egg):**
   - Trái tim hạt pha lê Lý Tuân phát sáng nhịp đập 60 FPS trên nền canvas nghệ thuật.
3. **Hiệu ứng & Âm thanh:**
   - Cánh hoa rơi lơ lửng SVG ngẫu nhiên, tự tắt khi người dùng bật reduced motion.
   - Nhạc nền piano dịu êm với nút bật/tắt an toàn.

## 🚀 Khởi Chạy Local

```bash
# Cài đặt thư viện
npm install

# Khởi chạy dev server
npm run dev

# Build production
npm run build
```
